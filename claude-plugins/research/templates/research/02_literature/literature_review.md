# Literature Review

## 1. Landscape

How the problem has been framed across communities, with the terminology differences named.

## 2. Clusters

Groups of papers actually solving the same problem. For each cluster, name the key differentiator.

## 3. Method comparison

What differs across methods, not just what exists. Use the matrix for detail.

## 4. Contradictions

Papers whose findings or assumptions conflict. Quote both sides with locators. If none were found, state the searches run.

## 5. Unresolved problems

Problems no located paper addresses, with the evidence that they are genuinely open.
